✅ CV Page Layout (recommended structure)
🧱 Page sections (top → bottom)
1. Hero / Header

First impression. Keep it simple.

Content:

Name (big)

Role: Frontend Developer / Web Developer

1-line tagline

Buttons: [View Projects] [Download CV]

Example:

Aditya Sahu
Frontend Developer

I build fast, responsive, modern websites using React & Vite.

[Projects]  [Download CV]

2. About Me

Short and human.

2–3 lines only:

I'm a BCA student and self-taught developer focused on React and modern web apps.
I enjoy building clean UI and solving real problems with code.
Currently looking for junior developer roles.

3. Skills (grid style)

Use small cards or tags.

Example:

Frontend: HTML CSS JavaScript React Vite
Tools: Git GitHub VS Code
Backend: Node basics / APIs
Other: Responsive Design UI/UX


Keep it scannable.

4. Projects (MOST IMPORTANT)

This is what recruiters actually care about.

Make cards:

Each project card should have:

Title

Screenshot

2 lines description

Tech stack

Live demo link

Code link

Example:

Student Management System
Console-based C++ app to manage records.
Tech: C++
[Live] [Code]


Tip: 3–5 good projects > 10 small ones.

5. Experience / Freelance

If you did:

freelance

internships

client work

college projects

List them here.

Format:

Freelance Web Developer — 2025
• Built marketing website for real estate agency
• Designed forms + chatbot
• Improved performance and SEO

6. Education

Simple:

BCA — XYZ College — 2025


No long story needed.

7. Contact

Make it easy.

Include:

Email

Phone

GitHub

LinkedIn

Optional: small contact form.

8. Footer

Small line:

© 2026 Aditya Sahu • Built with React + Vite
